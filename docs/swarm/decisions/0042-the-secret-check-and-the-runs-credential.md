# 0042. The secret check and the run's credential

Moved verbatim from `docs/swarm.md` section 14, item 42, on 2026-11-16. In the text, "item N" is decision N of this directory and "section N" is `docs/swarm.md` section N.

**The secret check and the run's credential.** `apply` knows the
exact value it handed over, so it refuses that value in what is
posted or pushed (7.6; a pattern scanner would guess), and each
`result` names its credential, never a value, so a login's quota use
is attributable. Grouping `status`'s Throughput by it is not built.
